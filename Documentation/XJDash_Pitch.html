XJDASH

A Modern Digital Dashboard for the 1990 Jeep Cherokee XJ

Open Source • Touch Screen • Fully Customizable • ~$175 Total

What Is It?

XJDash turns a Raspberry Pi and a 4.3" touchscreen into a full digital dashboard for your XJ. It reads live engine data from the Renix Engine Monitor (REM), displays it on customizable gauge screens, and controls up to 8 relays for fans, solenoids, light bars — whatever you want. All from a touch interface built for the trail.

🎯

Live Engine Data

RPM, coolant temp, MAP, TPS, O2, battery voltage, injector pulse width — everything the REM reports, in real time.

🎨

Custom Skins

Swap themes with JSON skin files. Classic amber LCD, green VFD, modern dark — or use your own background photo.

⚡

8-Channel Relay Control

RS485/Modbus relay module mounts under the hood. Control fans, AW-4 solenoids, light bars — from the touchscreen.

📊

Data Logging

SQLite logging with CSV export. Record every run, review trends, diagnose issues after the fact.

🔧

AW-4 Integration

Dedicated transmission screen for AW-4 automatic. Monitor and control shift solenoids directly.

📱

Touch-First UI

Designed for gloved hands and bouncy trails. Big buttons, swipe navigation, 4.3" portrait display.

Why Not Just Use a Phone?

Phone / Tablet

  • Overheats in a hot XJ cabin
  • Screen unreadable in direct sun
  • Can't control relays directly
  • Battery dies, needs charging
  • Notifications interrupt your gauges
  • Not permanently mounted
  • Bluetooth OBD2 doesn't work on Renix

XJDash

  • Passively cooled, no thermal throttle
  • IPS display readable at any angle
  • 8-channel relay control built in
  • Powered by ignition, always on
  • Single-purpose, no distractions
  • Permanently mounted, clean install
  • Direct USB to REM — made for Renix
